# Nalla-Nudi

Nalla-Nudi is an offline Android application designed to help Kannada-medium students understand technical English vocabulary used in higher education. Many students from rural and regional backgrounds understand academic concepts well but struggle with subject-specific English terms in Science, Mathematics, and Commerce. This application acts as a bridge dictionary that simplifies technical learning through the mother tongue.

The app allows users to search technical English words and receive simple Kannada explanations along with pronunciation guidance using Android Text-To-Speech (TTS). It also includes subject-wise filtering, a “Word of the Day” feature, and a personalized “My List” section where students can save difficult words for flashcard-style revision.

Built with a clean and student-friendly interface, Nalla-Nudi uses a preloaded Room Database to ensure fast search results and complete offline functionality. The project aims to reduce language barriers in STEM education, improve technical vocabulary skills, and build confidence among students transitioning to English-medium academics.

## Features
- Instant technical term search
- Kannada explanations for English words
- English pronunciation using TTS
- Subject-wise term filtering
- Offline access using Room Database
- Save difficult words for revision
- Flashcard-style learning
- Simple and educational UI

## Technologies Used
- Android Studio
- Kotlin
- Room Database
- Android Text-To-Speech (TTS)
- Material UI Components

## Objective
The main objective of Nalla-Nudi is to support equitable education by helping Kannada-medium students overcome language barriers and confidently learn technical subjects in English.
